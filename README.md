# Speedy Portfolio

A personal portfolio website built with the [al-folio](https://github.com/alshedivat/al-folio/tree/main) template, hosted via GitHub Pages using Jekyll.

🌐 **Live site:** [adamspeedy.github.io](https://adamspeedy.github.io)

---

## About

This is my personal portfolio site, showcasing my projects, experience, and background. It's built on the al-folio theme.
## Built With

- [Jekyll](https://jekyllrb.com/) — static site generator
- [al-folio](https://github.com/alshedivat/al-folio) — Jekyll theme
- [GitHub Pages](https://pages.github.com/) — hosting

## Local Development

To run the site locally:

```bash
# Install dependencies
bundle install

# Serve the site
bundle exec jekyll serve
```

Then open [http://localhost:4000](http://localhost:4000) in your browser.
